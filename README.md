# 展位排布工作台（Booth Layout Planner）

面向会展运营团队的展位排布工具：在 20 × 14 米展厅平面图上添加、拖动、缩放、旋转矩形展位，
**搭建前**自动发现展位重叠、通道过窄、出口被堵、疏散路径不可达等问题。纯前端实现，React + TypeScript + Vite，
数据保存在浏览器本地（localStorage），**不需要后端**。

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 本地开发，默认 http://localhost:5173
```

其他命令：

```bash
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览生产构建
npm test           # 运行全部单元测试（Vitest，一次约 4 秒）
npm run test:watch # 测试监听模式
npm run typecheck  # 仅做 TypeScript 类型检查
```

要求 Node.js ≥ 18。

## 功能一览

- **展厅平面**：20 × 14 m，南墙（x 3~5 m）、北墙（x 14~16 m）各一个固定安全出口。
- **展位编辑**：添加、拖动、8 个控制点缩放、90° 旋转（交换宽高），所有几何变化**吸附到 0.5 m 网格**。
- **画布缩放/平移**：滚轮以光标为锚点缩放、拖空白平移、右下角缩放按钮与“适应窗口”；
  缩放到任意倍率后，拖拽与缩放的坐标换算始终精确（世界坐标 = `(屏幕像素 − 平移) / 缩放`）。
- **撤销 / 重做 / 重置**：一次拖动或缩放只产生一条历史；支持 `Ctrl/⌘+Z`、`Ctrl/⌘+Y`（或 `Ctrl+Shift+Z`）；
  “方案重置 / 载入示例”本身也可撤销。
- **实时检查**（任何改动后立即重算，告警与路径同步更新）：
  - **越界**：展位超出 20 × 14 m 展厅边界；
  - **重叠**：两个展位发生面积相交，图上用红色斜纹标出重叠区域；
  - **净空不足**：正对的两边间距 < 1.5 m，图上画出带数值的尺寸标注；纯对角斜置不判定（斜角可通行）；
  - **出口被堵**：展位压住出口开口内侧网格，出口处显示红叉与“出口堵死”；
  - **疏散不可达**：从每个展位**正面接待点**（正面边中点外侧 0.25 m）在 0.5 m 网格上做 BFS，
    4 邻接、展位为障碍，到任一出口无路径时告警；可达时图上用绿色虚线画出实际可走路径。
- **告警上图 + 列表联动**：问题不只靠颜色——每个展位角上有“重/距/界/封/堵”字符徽标，
  右侧列表按严重度排序，点击任一告警会在图上高亮相关展位并选中，检查器同步显示原因与相关展位。
- **内置“出口被堵”示例**：首次打开即载入。左上角两面围挡与外墙合围困住 A01（不可达），
  B09 封住南出口。把“围挡-竖”拖开，A01 的绿色疏散路径会立刻出现、告警立即消失；
  拖开 B09，南出口立即解封。顶部“载入‘出口被堵’示例”可随时还原。
- **本地保存**：方案变更自动写入 `localStorage`（键 `booth-planner:plan:v1`），刷新不丢失。

> 另有一类对象是**围挡（partition）**：砖纹显示，是通道障碍（参与寻路阻挡、可封出口），
> 但没有接待点、不做 1.5 m 净空检查，两面围挡允许拼接，用来搭“封闭区”这类场景。

坐标约定：所有领域计算都以**米**为单位、展厅左上角为原点（x 向右、y 向下）；
屏幕上只在根 `<g>` 做一次 `translate(pan) scale(pxPerMeter)` 仿射变换。

### 关键算法说明

- **净空判定**：只在两个矩形于某一轴投影重叠（边对边）时检查另一轴间距，
  间距 `< 1.5 m` 告警；边重合（0 间距）属重叠；两轴都有正间距是对角关系，不约束。
- **寻路**：0.5 m 网格（40 × 28），展位覆盖的格子为障碍（边与格线重合不算阻挡，可贴边通行），
  从接待点对应格出发做 4 邻接 BFS，出口沿开口每 0.5 m 设一个目标格；先到的目标给出最近出口路径。
- **历史粒度**：拖动/缩放过程中只更新画面（不入栈），松手时把最终结果作为**一条**快照提交。

## 数据与隐私

所有方案数据仅保存在当前浏览器的 localStorage 中，不发起任何网络请求。
清空可使用工具栏“方案重置”，或手动清除站点数据。

## 搭建波次交接（Build Waves）

最终展位图通过消防检查，不等于搭建当天一次摆完——货箱、围挡、未安装展位分批进场，
上个班组把材料堆在北出口旁，交班后只看到最终方案仍是绿色。本功能把「计划冻结 → 分波 →
现场记录 → 按真实平面重算 → 留证 → 关闭 → 交接」整条链路做进工具。

**使用流程**

1. **冻结**（工具栏「🧊 冻结搭建计划」）：从当前方案生成一份不可变计划快照，
   弹窗里把围挡、展位分到不同波次（默认围挡第一波、展位第二波，支持 1~N 波）；
   冻结后继续编辑平面不再影响计划。
2. **分波与改线**：波次标签切换各波；未开工的件可在「计划中」波次间改派，
   **已关闭波次冻结，不能改派、不能被画布拖动覆盖**；进行中波次不允许新增波次。
3. **开工与班组交接**：填交班/接班班组后「🤝 班组交接」，自动在当时真实平面上留证；
   中断后刷新页面，从 localStorage 恢复现场（`activeWaveId` 回到进行中波次）。
4. **现场记录**：每件可记录 到场 → 暂存 → 安装 → 移位 → 撤场；
   安装/移位可带**实测占地**（在图上拖动已落地件即可，两阶段提交：拖动中只更新画面，
   松手追加一条测量记录+检查点；旋转钮同样留证），全部测量历史逐次保留。
5. **真实平面重算**：检查的障碍 = 前序已关闭波次遗留（图上锁标记、不可改）+
   本波已安装实测占地 + 本波暂存货箱（货箱占通道但无接待点，只作障碍）。
   每次记录/交接/关闭都在当时真实平面上重跑重叠、净空、出口、疏散 BFS，
   结果作为**检查点**追加保存、永不覆盖——第三波堵过北出口、撤料后最终变绿，
   那条红色检查点证据仍然可回看（侧栏检查点历史，画布只读还原当时平面）。
6. **临时堆放**：进行中波次双击空白可在该位置登记 2×1.5 m 暂存货箱，
   或在件清单标记「暂存」；临时堆放标记为 transient，当波撤场后不延续到后续波次。
7. **提前关闭 / 局部重演**：有未完成件也可提前关闭（自动标记 earlyClosed、
   未落地件写入差异）；「↺ 局部重演」重开已关闭波次补录，既有证据不删、只追加 amend。
8. **待核对区**：波次关闭后的迟到上报不直接入账，生成「迟到检查回执」进入待核对区，
   核对补录时追加 amend 检查点，或作废。
9. **两次搭建对比**：「🗂 归档并退出」把本次竣工实测存入归档（localStorage，最近 20 份），
   顶栏下拉选择另一次搭建，按展位 id 匹配，列出仅 A/仅 B 搭建、占地变化与一致件数；
   临时堆放不参与对比。
10. **撤销/重做**：搭建模式下 `Ctrl/⌘+Z` / `Ctrl/⌘+Y` 作用于波次操作历史，
    与平面编辑的撤销栈相互独立；平面编辑与实时告警在搭建模式自动停用以免串线。

**关键类型与模块**

- `src/types.ts`：`BuildPlan` / `Wave` / `BuildItem` / `WaveCheckpoint` / `ItemDiff` /
  `LateReceipt` / `BuildComparison`。
- `src/lib/waves.ts`：冻结、分波、真实平面推导（`floorForWave`）、检查点重算
  （`evaluateAt`）、差异（`diffsForWave`）、改线边界、迟到回执、重演、对比；
  纯函数 + 注入时间戳。
- `src/lib/validation.ts`：`analyzePlan` 新增 `skipPathIds`（暂存货箱只作障碍）。
- `src/state/useBuildPlan.ts`：搭建工作台状态、独立撤销栈、localStorage 恢复。
- `src/components/`：`FreezeDialog`、`WavePanel`（含待核对区、对比面板）、
  `FloorPlan` 新增 `view` 宿主（真实占地、锁定遗留、计划虚影、只读历史回看）。
